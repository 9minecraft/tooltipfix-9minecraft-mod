# ToolTipFix — Read Every Item Tooltip Clearly in Your Inventory

ToolTipFix 9minecraft Mod stops long item text boxes from running off the screen. It keeps descriptions, lore, and enchantment lists inside your view by wrapping text onto new lines. You can read every detail on modded gear or items with lots of text without missing words past the border. The mod runs entirely on your client and works in singleplayer worlds as well as multiplayer servers.

Wraps long lines of tooltip text so everything fits inside the game window.

## What this build is

An unofficial rebuild of **kyrptonaught**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
